# Design decisions

Hallmark Console: graphite surfaces, pale type, amber controls and blue measurements. The page is an engineering narrative rather than a live operations dashboard. Original exported outcomes are the visual material.

The custom hero places a score comparison below its headline; rendered screenshots confirm that it fills the first viewport. Text-bound heuristics miss this comparison (waivers 44c and 79). Case-selection cells deliberately exceed ordinary button height to hold both identifier and outcome (39b). The closing evidence section uses three broad metric rows, rather than an invented image (77). Different column gaps suit the four-stage architecture, twenty-case grid and two-run comparison.

Motion is user controlled. Reduced motion, keyboard focus, textual pass/fail labels, source downloads and visible failures support an accessible, honest recording.
